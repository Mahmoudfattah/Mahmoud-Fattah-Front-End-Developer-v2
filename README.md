# Mahmoud Fattah Portfolio

A modern, animated, and interactive portfolio web application built with React, Framer Motion, and Tailwind CSS. Showcasing projects, skills, and contact information with smooth scrolling and engaging UI effects.

## Features
- Animated intro splash screen
- Smooth scrolling navigation
- Responsive design for all devices
- Interactive sections: About, Services, Projects, Skills
- Lottie animations and custom cursor
- Framer Motion transitions
- Downloadable CV

## Installation

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   cd MyAppFull
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start the development server:**
   ```bash
   npm run dev
   ```
4. Open [http://localhost:5173](http://localhost:5173) in your browser.

## Usage
- Navigate through the sections using the navigation dots or animated buttons.
- Download the CV from the top section.
- Explore projects and skills interactively.

## Technologies Used
- **React** (Vite)
- **Framer Motion** (animations)
- **Tailwind CSS** (styling)
- **Lottie** (animations)
- **Lucide React** (icons)
- **@studio-freight/lenis** (smooth scrolling)
